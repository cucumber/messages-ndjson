# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/)
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

## [0.5.1] - 2026-06-23
### Fixed
- Added `Json.instance()` to obtain an instance using SPI.

## [0.5.0] - 2026-06-22
### Changed
- Make Jackson an optional non-shaded dependency
- Support Jackson 2 and Jackson 3
- Add `module-info.java`
- Use JSpecify for nullability

## [0.4.1] - 2026-03-02
### Changed
- Update dependency com.fasterxml.jackson:jackson-bom to v2.21.1

## [0.4.0] - 2026-01-21
### Changed
- Set release version to 17 ([#4](https://github.com/cucumber/messages-ndjson/pull/4))

## [0.3.3] - 2026-06-26
### Changed
- Update dependency com.fasterxml.jackson:jackson-bom to v2.22.0

## [0.3.2] - 2026-03-04
### Changed
- Actually update dependency com.fasterxml.jackson:jackson-bom to v2.21.1

## [0.3.1] - 2026-03-03
### Changed
- Update dependency com.fasterxml.jackson:jackson-bom to v2.21.1

## [0.3.0] - 2026-01-14
### Added
- Add OSGI module name ([#3](https://github.com/cucumber/messages-ndjson/pull/3))

### Fixed
- Improved Javadoc

## [0.2.0] - 2026-01-12
### Added
- Update dependency io.cucumber:messages to v32.0.0

## [0.1.0] - 2026-01-12
### Added
- Java implementation ([#1](https://github.com/cucumber/messages-ndjson/pull/1))
